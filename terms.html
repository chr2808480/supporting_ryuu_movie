　利用規約

制定日：要記入：公開日

ファン交流スペース「星軍基地」を使うときの約束ごとです。毎日の過ごし方は「基地のルール」にまとめています。この規約は、そのルールを支える土台の決まりです。

かんたんに言うと

  • 星軍基地は、ファンが個人で、無料・非営利で運営する非公式の場所です。
  • 参加登録できるのは16歳以上の方です。18歳未満の方は保護者の同意を得てください。
  • 投稿の著作権は投稿した人のものです。運営者は基地での表示に必要な範囲でだけ使います。
  • 違反には段階を追って対応し、処置の理由と異議の申立て方を必ず伝えます。
  • 規約を変えるときは、14日前までにお知らせします。

この囲みは要約です。正式な内容は、以下の各条のとおりです。

第1条（この規約について）

  1. この利用規約（以下「本規約」）は、ryuu星軍 本部の運営者（以下「運営者」）が提供するファン交流スペース「星軍基地」（以下「基地」）を利用するときの条件を定めるものです。
  2. 基地のルールは、本規約の一部です。本規約と基地のルールの内容が食い違うときは、本規約が優先します。
  3. 預かる情報の扱いは、プライバシーポリシーに定めます。
  4. 参加登録の画面で「利用規約と基地のルールに同意します」を選んだ方は、本規約に同意したものとします。
  5. 登録せずに読むだけの方も、投稿の無断転載をしない（第6条第4項）など、ほかの利用者を守るための決まりにご協力ください。

第2条（星軍基地とは）

  1. 基地は、声真似配信者 RyuU さんのファンが、配信や動画の感想などを語るための非公式・非営利の交流スペースです。
  2. 運営者はファン個人であり、RyuU さんご本人および関係各所とは関係ありません。基地での投稿や運営者の発信は、RyuU さんご本人や関係各所の公式な見解ではありません。
  3. 基地の利用は無料です。運営者は、基地で広告の掲載や有料のサービスを行いません。

第3条（利用できる人）

  1. 投稿・返信・★・ミュート・ブロック・通報を使うには、参加登録が必要です。読むだけなら登録はいりません。
  2. 参加登録できるのは16歳以上の方です。16歳未満の方は登録できません。
  3. 18歳未満の方は、親権者など法定代理人の同意を得てから登録してください。
  4. 次のいずれかに当たる方は登録できません。登録の後で当てはまると分かったときは、運営者は登録を取り消すことがあります。
    1. 16歳未満の方、または年齢を偽って登録した方
    2. 過去に基地の利用停止を受けた方（運営者が再登録を認めた場合を除きます）
    3. 自分のものではないメールアドレスで登録した方

第4条（アカウントの管理）

  1. アカウントは1人につき1つです。
  2. ログインは、登録したメールアドレスに届くリンクで行います（パスワードはありません）。ログイン用のリンクや、登録したメールアドレスの受信箱を、他人に使わせないでください。
  3. 表示名には、本名・SNSのアカウント・学校名・勤務先・連絡先を使わないでください。表示名は、同じ人の発言だと分かるよう固定です。個人情報を含めてしまったなど、変更が必要なときはお問い合わせフォームから運営者に連絡してください。
  4. 自分のアカウントが他人に使われていると気づいたときは、すぐに運営者に知らせてください。

第5条（投稿のしくみと制限）

基地を落ち着いて語れる場所に保つため、次のしくみを設けています。しくみの細かい内容は、お知らせ欄で予告したうえで調整することがあります。

  1. 毎日23:00〜6:00（日本時間）と、運営者が不在の日は、新規投稿をお休みします。閲覧はいつでもできます。
  2. リンクを含む投稿は、運営者が確認してから公開します。
  3. 同じ相手への返信は、24時間で3回までです。
  4. 投稿は1件1000文字までです。
  5. 投稿の前に、電話番号・住所・メールアドレスらしい文字列があると注意を表示します。この注意は目安で、すべての個人情報を見つけられるわけではありません。投稿の内容には、投稿した方が責任を持ってください。
  6. 投稿と返信は、ログインしていない人も含めて誰でも見られます。

第6条（投稿の権利）

  1. 投稿・返信の著作権は、投稿した方に残ります。運営者に移ることはありません。
  2. 投稿した方は、運営者が、基地を運営するのに必要な範囲（基地での表示、保存とバックアップ、ネタバレの折りたたみ表示、違反への対応のための確認と記録）で投稿を無償で利用することを認めるものとします。
  3. 運営者は、投稿した方の同意なく、投稿を基地の外（SNS・ほかのサイト・印刷物など）で使いません。
  4. ほかの方の投稿を、投稿した方の許可なく基地の外へ転載しないでください。
  5. 他人の著作物（動画・配信・画像・ファンアートなど）は、権利者の許可がある場合か、法律で認められた引用の範囲でのみ投稿してください。

第7条（禁止事項）

基地では、基地のルールの「禁止事項」に当たる行為のほか、次の行為を禁止します。

  1. 法令や公序良俗に反する行為、犯罪につながる行為
  2. 他人の著作権・肖像権・プライバシー・名誉などの権利を侵害する行為
  3. 基地のサーバーに過度な負荷をかける行為、不正アクセス、しくみの不具合を悪用する行為
  4. プログラムによる自動投稿や、投稿・表示名の大量収集
  5. 年齢やメールアドレスを偽っての登録、他人のアカウントの利用
  6. 運営者を装って、ほかの利用者からログイン用のリンクやメールアドレスを聞き出す行為
  7. 前の各号に準じる行為で、ほかの利用者や RyuU さん・関係者に迷惑をかけるもの

第8条（違反への対応）

  1. 運営者は、本規約や基地のルールに違反する投稿・行為を見つけたときは、基地のルールの「違反があったとき」に書いた段階（運営からの注意 → 投稿の非表示 → 7日間の投稿停止 → 利用停止）に沿って対応します。
  2. 個人情報の晒し、脅迫、RyuU さんや他の配信者への加害など、人の生命・身体・財産や名誉に重大な被害が生じるおそれがあるときは、段階を飛ばして、すぐに投稿の非表示や利用停止を行います。
  3. 権利を侵害されたという申出（削除依頼）を受けたときは、法令（情報流通プラットフォーム対処法など）に沿って内容を確認し、投稿を非表示にすることがあります。必要に応じて、投稿した方に意見をお聞きします。
  4. 処置をしたときは、登録したメールアドレスに、次のことを知らせます。通報した人が誰かは知らせません。
    1. どの投稿・行為が、どのルールに当たるか
    2. 処置の内容と期間
    3. 異議の申立て方
  5. 処置に納得できないときは、通知を受け取った日から要記入：14日以内に、お問い合わせフォームから異議を申し立てられます。異議の申立ては、1つの処置につき1回です。運営者は内容を確かめ直し、結果と理由をお知らせします。処置が誤りだったときは、投稿を元に戻し、違反の記録を取り消します。
  6. 運営者は個人で運営しているため、すべての投稿を前もって確認することはできません。違反には、主に通報と運営者の見回りで気づきます。

第9条（通報・ミュート・ブロック）

  1. 本規約や基地のルールに反すると思う投稿は、投稿の「…」から通報できます。通報したことや、通報した人が誰かは、法令に基づく場合を除き、投稿した方には知らせません。
  2. 通報を受けても、運営者が確かめた結果、処置をしないことがあります。
  3. ミュートとブロックは、相手に知らされません。

第10条（発信者情報の開示など）

  1. 運営者は、法令に基づく開示請求や裁判所の命令を受けたときは、法令の範囲で、投稿した方の情報（投稿時のIPアドレスと日時、メールアドレスなど）を開示することがあります。
  2. 開示請求を受けたときは、法令に従い、開示に応じるかどうかについて、登録したメールアドレスで投稿した方の意見をお聞きします。
  3. 人の生命や身体に危険が迫っているときなど、法令で認められる場合には、警察などの公的機関に情報を提供することがあります。

第11条（退会）

  1. マイメニューの「退会する」から、いつでも退会できます。
  2. 退会すると、その方の投稿・返信・メールアドレスは削除され、元に戻せません。ただし、プライバシーポリシーに書いた一部の記録（投稿時のIPアドレスと日時など）は、そこに定めた期間が過ぎるまで保存します。

第12条（基地の変更・お休み・終了）

  1. 運営者は、基地の機能を変えたり、点検や運営者の不在のために基地を一時的に止めたりすることがあります。できるだけ前もってお知らせ欄で知らせます。
  2. 運営者は、基地を終えることがあります。終えるときは、原則として要記入：30日前までに、お知らせ欄と登録したメールアドレスで知らせます。終えた後は、預かった情報をプライバシーポリシーに沿って削除します。
  3. RyuU さんご本人や関係各所から求めがあったときは、前もって知らせずに、基地を止めたり終えたりすることがあります。

第13条（責任について）

  1. 基地は、ファン個人が無償で運営しています。運営者は基地を安全に運営するよう努めますが、不具合や中断が起きないこと、投稿の内容が正確であることまでは約束できません。
  2. 利用者どうしのトラブルは、当事者の間で話し合って解決してください。運営者は、基地のルールに沿った処置と、法令に基づく対応の範囲で協力します。
  3. 運営者の故意または重大な過失によって利用者に損害が生じたときは、運営者は法令に従ってその損害を賠償します。
  4. 運営者の軽過失（重大な過失ではない過失）によって利用者に損害が生じたときは、運営者は、直接かつ通常の損害に限って賠償します。この制限は、運営者に軽過失しかない場合にだけ適用し、人の生命・身体に関わる損害には適用しません。
  5. 利用者が本規約に違反して、運営者やほかの方に損害を与えたときは、その利用者が賠償の責任を負います。

第14条（規約の変更）

  1. 運営者は、次のいずれかに当たるときに、本規約を変更することがあります（民法第548条の4）。
    1. 変更が、利用者全体の利益に合うとき
    2. 変更が、基地の目的に反せず、変更の必要性・変更後の内容の相当性などに照らして合理的なとき
  2. 変更するときは、変更後の内容と、変更の効力が生じる日を、その日の14日前までに、お知らせ欄とこのページで知らせます。利用者に不利な変更は、登録したメールアドレスにも知らせます。

第15条（連絡のしかた）

  1. 運営者から利用者への連絡は、登録したメールアドレスへのメール、または基地のお知らせ欄で行います。
  2. 利用者から運営者への連絡は、お問い合わせフォームで受け付けます。

第16条（準拠法と裁判所）

  1. 本規約は、日本の法律に従って解釈します。
  2. 基地について争いが生じたときは、まず話し合いでの解決に努めます。それでも解決しないときは、民事訴訟法の定めに従って管轄を持つ裁判所で解決します。

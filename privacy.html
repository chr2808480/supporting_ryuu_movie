　プライバシーポリシー

制定日：2026年10月23日

ファン交流スペース「星軍基地」と、削除依頼・お問い合わせのフォームで預かる情報と、その扱いです。他の利用者に見えるのは表示名と投稿だけです。運営者に預ける情報も、基地の運営と違反への対応に必要な最小限にします。

かんたんに言うと

  • 本名・住所・電話番号・生年月日は集めません。
  • メールアドレスはログインと大事な連絡にだけ使い、ほかの利用者には見せません。
  • 広告やアクセス解析のタグは使いません。
  • 預かった情報を売ったり、法令に基づく場合などを除いて他人に渡したりしません。
  • 退会すると、投稿・返信・メールアドレスを削除します。

この囲みは要約です。正式な内容は、以下の各項目のとおりです。

3. 使いみち（利用目的）

預かった情報は、次の目的にだけ使います。

  1. 参加登録の受付と、ログイン用リンクの送信
  2. 投稿・返信・★・ミュート・ブロック・通報など、基地の機能の提供
  3. 利用規約や基地のルールへの違反の確認、処置とその通知、異議への対応
  4. 荒らし・なりすまし・処分の回避の防止
  5. 削除依頼・お問い合わせへの対応と返信
  6. 法令に基づく開示請求への対応（投稿した方への意見照会を含みます）
  7. 規約の変更や基地の終了など、重要なお知らせ

使いみちを変えるときは、法令で認められる範囲に限り、前もってこのページとお知らせ欄で知らせます。

4. 情報の集め方

  • 参加登録・投稿・通報・お問い合わせのときに、ご本人に入力していただいた情報を預かります。
  • 投稿・返信・編集をしたときに、IP アドレスと日時を自動で記録します。
  • 偽りその他の不正な手段で情報を集めることはしません。
  • 病歴や信条など、特に配慮が必要な情報を集めることはしません。ご自分の投稿にも書かないようお願いします。

5. 第三者への提供

ご本人の同意なく、個人情報を第三者に提供しません。売ることもしません。ただし、個人情報保護法第27条第1項に定める次のような場合を除きます。

  1. 法令に基づく場合（裁判所の命令、情報流通プラットフォーム対処法に基づく発信者情報の開示請求など）
  2. 人の生命・身体・財産を守るために必要で、ご本人の同意を得ることが難しい場合
  3. 公衆衛生の向上や児童の健全な育成のために特に必要で、ご本人の同意を得ることが難しい場合
  4. 国の機関などが法令の定める事務を行うことに協力する必要があり、ご本人の同意を得るとその事務に支障が出るおそれがある場合

次の項目の外部サービスに取扱いを任せること（委託）は、第三者への提供には当たりません（同条第5項第1号）。

外国の個人情報保護の制度

情報を外国で扱うため、その国の制度を確かめたうえで、次の項目の対策をとっています。

  • 米国：個人情報の保護に関する包括的な連邦法はなく、分野ごとの法律や州の法律で保護されています（個人情報保護委員会「外国制度（アメリカ合衆国）」）。
  • シンガポール：民間の事業者を対象とする包括的な法律として、個人データ保護法（Personal Data Protection Act 2012）があります（個人情報保護委員会「外国制度（シンガポール共和国）」）。

Gmail のサーバーの国は特定できません。Google は、情報を世界各地のサーバーで処理することがあると公表していて（Google プライバシー ポリシー）、保存する国を利用者が選べないためです。参考として、Google が公表しているデータセンターの所在国は、米国・チリ・アイルランド・オランダ・デンマーク・フィンランド・ベルギー・ドイツ・台湾・シンガポール・日本です（Google「Data Center Locations」、2026年10月に確認）。上に書いた国のほかの制度は、次のとおりです。

  • アイルランド・オランダ・デンマーク・フィンランド・ベルギー・ドイツ：EU の一般データ保護規則（GDPR）が適用され、個人情報保護委員会が、日本と同等の水準の制度を持つ国として指定しています（個人情報保護委員会「平成31年個人情報保護委員会告示第1号」）。
  • 台湾：包括的な法律として、個人資料保護法があります（個人情報保護委員会「外国制度（台湾）」）。
  • チリ：包括的な法律として、私生活の保護に関する法律（法律第19.628号）があります。2024年12月に公布された改正法（法律第21.719号）で、監督機関（個人データ保護庁）が置かれることになっています（チリ国会図書館「Ley 21.719」）。

任せる先がとっている対策

  • EmailJS：保存するデータを暗号化し、米国の Amazon Web Services のサーバーで運用しています（EmailJS プライバシーポリシー）。運営者は、入力内容の履歴を EmailJS に残さない設定で使います。
  • Firebase（Google）：すべてのサービスで ISO 27001 と SOC 1・2・3 の評価を受け、通信を暗号化（HTTPS）し、Cloud Firestore と Authentication は保存するデータも暗号化しています（Privacy and Security in Firebase）。
  • Gmail（Google）：メールは、保存中も、Google のデータセンターの間を送るときも暗号化しています（Google セーフティ センター「Gmail」）。ほかのメールサービスとのやりとりも、相手が対応していれば暗号化（TLS）します（Gmail ヘルプ「Gmail でメールが暗号化される仕組み」）。個人情報にアクセスできる担当者を、処理に必要な社員などに限り、契約上の守秘義務を課しています（Google プライバシー ポリシー）。運営者は、運営専用のアカウントを使い、二段階認証で守ります。

外国にある事業者に個人データの取扱いを任せるときは、個人情報保護法第28条に従い、あらかじめ国名などの情報をお伝えしたうえでご本人の同意をいただきます。Firebase と Gmail については参加登録の画面で、EmailJS と Gmail についてはお問い合わせフォームで、同意をいただいています。

7. 安全のためにしていること

  • 基本方針：このページで、情報の扱いの方針を定めて公開しています。
  • 扱い方の決まり：預かった情報を扱えるのは運営者だけです。集める・使う・保存する・削除するときの手順を決めています。
  • 組織的な対策：運営者が責任者です。漏えいなどに気づいたときの連絡と対応の手順を決めています。
  • 人的な対策：運営を手伝う人を置くときは、情報を外に漏らさないことを約束してもらい、扱い方を伝えます。
  • 物理的な対策：管理に使う端末には画面ロックをかけ、なくしたときに遠隔でロック・消去できるようにしています。
  • 技術的な対策：管理画面と外部サービスのアカウントを二段階認証で守ります。通信は暗号化（HTTPS）します。投稿時の IP アドレスは、秘密の鍵（Google Cloud の Secret Manager に保管）で暗号化して保存し、保存期間が過ぎた情報は自動で削除します。投稿などの書き込みはすべてサーバー側で確かめてから保存し、他の利用者の非公開の情報は画面から読めないようにしています。
  • 外的環境の把握：前の項目に書いた国の制度を確かめたうえで、これらの対策をとっています。

安全のためにここに書いていない対策の内容は、ご本人から求めがあればお答えします。

8. ブラウザへの保存と外部への送信

  • 星軍基地のページは、このサイトの中にあるファイルだけを読み込みます。広告・アクセス解析・SNSのボタンなど、見た人の情報をほかの事業者に送るしくみは使いません。投稿の表示・ログイン・書き込みのために、6. の Firebase（Google）のサーバーとやりとりします。このとき、IP アドレスやブラウザの種類などが Google に送られます。
  • ログイン状態を保つため、ブラウザの保存領域（IndexedDB の firebaseLocalStorageDb）に情報を保存します。ログアウトすると削除されます。
  • ログイン用リンクを送るとき、メールアドレスと希望した表示名をブラウザ（localStorage の hiroba.pendingSignIn）に一時保存します。リンクからログインした時点で削除します。
  • 運営者が Cookie を設定することはありません。
  • このサイトは GitHub Pages（GitHub, Inc.・米国）で配信しています。GitHub は、ページを見た人の IP アドレスをセキュリティのために記録しています（GitHub Docs「What is GitHub Pages?」）。この記録は GitHub が扱うもので、運営者は受け取りません。
  • お問い合わせフォームのページでは、送信のために EmailJS のプログラムを jsDelivr（ファイル配信サービス）から読み込みます。このとき、IPアドレスやブラウザの種類などが jsDelivr に送られます。

9. 開示・訂正・削除などの請求

ご自分の情報について、次のことを請求できます（個人情報保護法第32条〜第35条）。

  • 利用目的のお知らせ、預かっている情報の開示（電子データでの提供も選べます）
  • 第三者に提供した記録の開示
  • 内容が事実と違うときの訂正・追加・削除
  • 利用の停止・消去、第三者への提供の停止

投稿の削除と退会は、マイメニューからご自分でもできます。

請求のしかた

  1. お問い合わせフォームで、種類に「個人情報の開示・削除などの請求」を選び、表示名と請求の内容を書いて送ってください。返信先には、登録しているメールアドレスを書いてください。
  2. ご本人の確認のため、登録しているメールアドレスに確認のメールを送ります。
  3. 代理人（法定代理人、またはご本人から頼まれた代理人）による請求のときは、代理の権限を確かめる書類をお願いすることがあります。
  4. 手数料はいただきません。
  5. 遅滞なく（目安として14日以内に）お答えします。請求に応じられないときは、その理由をお知らせします。

10. 16歳未満の方の情報

星軍基地は16歳以上の方が対象です。16歳未満の方の登録が分かったときは、アカウントと預かった情報を削除します（法令に基づいて保存が必要なものを除きます）。

情報の扱いについてのご質問・苦情・削除のご依頼は、お問い合わせフォームからご連絡ください。
